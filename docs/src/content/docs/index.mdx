## Quick start

```bash
composer create-project skim/framework my-app
cd my-app
cp .env.example .env
docker compose up -d
php skim migrate
```

## Generate docs

```bash
php skim docs:extract   # scan @ai.* annotations → llm.json
php skim docs:llm       # llm.json → llm.md (paste into any LLM)
php skim docs:site      # llm.json → this site (MDX files)
```

## API Reference

The API reference is auto-generated from `@ai.*` PHPDoc annotations in the source.
Run `php skim docs:site` to regenerate it after making changes.
