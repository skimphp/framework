---
title: Database & ORM
description: Work with raw queries, the query builder, and Active Record ORM in SKIM.
---

SKIM provides a database toolkit spanning three distinct layers: raw SQL, a fluent Query Builder, and an Active Record ORM.

### 1. Raw Queries

For ultimate performance and transparency, use `db::` facade direct queries:

```php
$users = db::all("SELECT * FROM users WHERE active = ?", [1]);
$user = db::row("SELECT * FROM users WHERE id = ?", [3]);
$count = db::val("SELECT COUNT(*) FROM users");
```

### 2. Query Builder

Construct queries programmatically using a fluent interface with automatic parameter binding:

```php
$users = db::table('users')
    ->where('active', '=', 1)
    ->where_null('deleted_at')
    ->order_by('created_at', 'DESC')
    ->get();
```

### 3. Active Record ORM

Extend `Model` (or `MerryModel`) to interact with your tables as objects:

```php
class User extends Model {
    protected static string $table = 'users';
}

// Fetch and update
$user = User::find(1);
$user->email = 'new@example.com';
$user->save();
```

<NoteBox>
**The `db::null()` Sentinel**

When updating columns to `NULL` via the Query Builder or Active Record, SQL parameters can easily trip up simple binding libraries. In SKIM, if you need to explicitly bind and persist a literal SQL `NULL` value, use the `db::null()` sentinel.

```php
db::table('users')
    ->where('id', '=', 1)
    ->update(['suspended_at' => db::null()]);
```
</NoteBox>
